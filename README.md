# Netflix Country Trend Analysis

This project analyzes Netflix's content catalog to identify which countries contribute the most titles and how this has changed over time.

Using Python (pandas, matplotlib), the data is cleaned, transformed, and explored to uncover global trends in streaming content distribution.

## Key Questions
- Which country contributes the most titles to Netflix?
- How has content production evolved over time?
- What trends show Netflix’s global expansion?

## Key Insights
- The United States dominates Netflix content contributions
- India and the UK are among the fastest-growing contributors
- Significant global growth occurs after 2015
- Content diversity increases sharply from 2018 onward

## Tools Used
- Python (pandas, matplotlib)
- Jupyter Notebook

## Dataset
Netflix Titles Dataset (CSV)
